# MARBALL 7v7 League

## Run
Install Node.js 18+, open this folder in a terminal, then:
`npm install`
`npm start`
Open `http://localhost:3000`.

## Use
Admin > Add Match. Scorers and assists are comma-separated player names, one entry per goal/assist. Cards use one per line, e.g. `Player Two - yellow`.

## Important
This starter stores data in `data.json`. For a public production league, add real authentication and use a hosted database/persistent server storage before opening the admin panel publicly.
